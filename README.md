# Jesse Benavidez Personal Portfolio

This repository contains my personal portfolio website created for CS 3365 Software Engineering at Texas Tech University.

The purpose of this project is to demonstrate the use of Git and GitHub during the software development process, including commits, feature branches, merging, pushing, pulling, and GitHub Pages deployment.

## Portfolio Sections

The website includes:

- Home
- About Me
- Skills
- Projects
- Contact

## Technologies Used

- HTML
- CSS
- Git
- GitHub
- GitHub Pages

## Projects

### Digital Buck Converter
A digitally controlled buck converter developed using an ESP32 with PWM control, voltage and current monitoring, closed-loop output control, and a web-based dashboard.

### SCADA Dashboard
A SCADA-style monitoring dashboard used to display system process data, equipment status, power information, and network-connected devices.
